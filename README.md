Entry for the [One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f) bounty on make.fun.

The program writes exactly one emoji — a hatching chick 🐣 — to `entry.txt`
and nothing else: no words, no caption, no explanation. A baby chick
breaking out of its shell reads as warm, friendly and gently funny at
first glance, the same way to a stranger of any age or background.

## Run

```sh
node main.ts --output /output
```

or set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
